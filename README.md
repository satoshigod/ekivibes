# Ekivibes Backend

Backend de ecommerce para Ekivibes - Tienda de equitación Colombia 🇨🇴🐴

Construido con [Medusa v2](https://medusajs.com/) y [Supabase](https://supabase.com/).

## Stack
- **Backend:** Medusa v2
- **Base de datos:** Supabase (PostgreSQL)
- **Deploy:** Railway
- **Frontend:** Next.js en Vercel

## Variables de entorno
Ver `.env.template` para la configuración requerida.
